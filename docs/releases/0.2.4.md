# BR Fut 0.2.4

Correção estável da busca do Mercado.

- Os filtros de Overall, idade, valor de passe e salário aceitam digitação manual no aplicativo desktop.
- Valores monetários digitados com `R$`, pontos ou espaços são interpretados corretamente ao pesquisar.
- Todos os campos de busca podem aplicar o filtro com Enter; o botão **PROCURAR** continua disponível.
- O foco do campo fica visível e a edição não é interrompida enquanto o jogador digita.
