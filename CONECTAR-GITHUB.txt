=== DOMINIO brfut.com.br (REGISTRO.BR → GITHUB PAGES) ===

Erro atual no GitHub: "NotServedByPagesError" / "DNS check unsuccessful"
Causa: brfut.com.br ainda NAO tem registros A apontando para o GitHub.

PASSO A — REGISTRO.BR (DNS)
---------------------------
1. https://registro.br — login → Painel → brfut.com.br
2. Secao DNS (tela que voce ja viu):
   - Deve aparecer: "Voce esta utilizando os servidores DNS do Registro.br" ✓
   - NAO clique em "Alterar servidores DNS"
   - Clique em **Configurar enderecamento** (seta >)
3. Na tela seguinte, escolha **Modo avancado** e confirme.
   (O "Modo avancado" so aparece DEPOIS de "Configurar enderecamento".)
4. **Aguarde a transicao terminar** — enquanto durar, a zona fica bloqueada:
   mensagem "Dominio em transicao. Por favor, aguarde alguns minutos..."
   O contador na tela pode mostrar ~2h; quando liberar, a tabela deixa
   adicionar entradas (deixa de mostrar "Nenhum dado encontrado" sem botao).
5. Volte em DNS → **Configurar zona DNS** → **Nova entrada**
6. Adicione os registros (Registro.br NAO aceita @ no nome — deixe vazio):

   Tipo A    | Nome (entrada) — VAZIO para raiz | Dados
   ----------|----------------------------------|------------------
   A         | (vazio)                          | 185.199.108.153
   A         | (vazio)                          | 185.199.109.153
   A         | (vazio)                          | 185.199.110.153
   A         | (vazio)                          | 185.199.111.153

   Tipo CNAME | Nome   | Dados
   -----------|--------|----------------------
   CNAME      | www    | vinaogamez.github.io

7. **Salvar alteracoes**. Propagacao: de minutos a algumas horas (ate 24h).

PROBLEMA COMUM: painel mostra entradas, mas internet nao ve A/CNAME
-------------------------------------------------------------------
Se GitHub continua "DNS check unsuccessful" apos horas:
1. Confirme **Salvar alteracoes** (verde no fim da pagina).
2. Valide na internet (PowerShell):
     Resolve-DnsName brfut.com.br -Type A -Server a.auto.dns.br
   Deve listar 4 IPs 185.199.108-111.153. Se so aparecer SOA/MX/TXT,
   os registros NAO foram publicados — reabra a zona e recadastre.
3. Ao criar cada A: campo Nome **vazio** (nao @). A tabela pode exibir
   "brfut.com.br" so na listagem — ok. CNAME: Nome **www** (nao www.brfut.com.br).
4. Remova entradas MX/TXT conflitantes se a zona nao deixar salvar A.
5. Se persistir: suporte Registro.br ou DNS externo (Cloudflare) depois.

Enquanto DNS nao propaga: GitHub Pages → **Remove** custom domain
para liberar https://vinaogamez.github.io/BRFut/home.html
